# 小红书AI运营助手 — 重构迭代方案

> 基于用户反馈 + 实际使用场景 | 2026-05-06

---

## 一、用户使用场景还原

```
第一次使用：
  添加账号 → 粘贴主页URL → 选择采集方式 → 等待采集完成
  ↓
  （本地已有账号的全部笔记数据）

日常工作流（每天/每周循环）：
  ① 看数据 → 这个账号最近表现怎么样？
  ② 看分析 → AI 给了什么优化建议？
  ③ 创作笔记 → 基于建议，用 AI 生成一篇新笔记
  ④ 发布后追踪 → 过了几天再来看看这篇笔记的互动数据
  ↓
  循环 ①→④，持续优化内容质量
```

**核心洞察：** 整个产品围绕**一个账号**运转。用户不需要在"账号分析"和"数据洞察"之间来回切换 —— 这些应该是一体的。

### 3.3 内容库（重新定义为纯素材管理）

**定位变更：** 从「跨账号笔记视图」改为「纯内容资产管理」

**核心概念：** 内容库是素材仓库，存储账号采集时提取的图片、视频、文案原文等原始素材。与笔记（XhsPost）不产生关联。

```

│                                          │
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐    │

│  │ 来源A│ │ 来源B│ │ 来源A│ │ 来源C│    │
│  └──────┘ └──────┘ └──────┘ └──────┘    │
│                                          │
│  [ 批量导出 ] [ 批量删除 ]                │

```

**内容类型：**
- **文字类：** 采集到的笔记文案原文、标题
- **图片类：** 笔记中的图片（本地存储，非小红书链接）
- **视频类：** 笔记中的视频文件（如可下载则存储，否则存链接）

**数据来源：** 账号采集时自动归档到内容库

**数据库设计：** 新增 `ContentAsset` 模型，独立于 `XhsPost`

### 3.4 仪表盘（简化）

仪表盘变为**轻量汇总页**：

- 账号总数 / 笔记总数 / 平均互动
- 最近采集动态（最近 5 条）
- 待处理草稿数
- 快捷按钮：添加账号 / 创作笔记 / 查看热门笔记
- **移除**：热门话题模块（数据过时，维护成本高）
- **移除**：AI 策略推荐（与账号中心的 AI 洞察重复）

## 四、数据模型变更

```prisma
// 新增字段 - XhsPost（笔记）
model XhsPost {
  // ... existing fields ...
  postType      String   @default("normal") // normal, video
  videoUrl      String   @default("")       // NEW: 视频URL
  duration      Int      @default(0)        // NEW: 视频时长(秒)
}

// 新增模型 - 内容资产（素材管理，不与笔记关联）
model ContentAsset {
  id            String   @id @default(cuid())
  accountId     String   // 来源账号
  assetType     String   // text, image, video
  filePath      String   @default("")       // 本地存储路径
  originalUrl   String   @default("")       // 原始链接
  title         String   @default("")       // 标题/文案内容
  thumbnailPath String   @default("")       // 缩略图路径（视频用）
  fileSize      Int      @default(0)        // 文件大小(字节)
  scrapedAt     String   @default("")       // 采集时间 YYYY-MM-DD
  createdAt     DateTime @default(now())

  @@index([accountId])
  @@index([assetType])
  @@index([scrapedAt])
}

// 新增模型（排程数据持久化）
model ContentSchedule {
  id            String   @id @default(cuid())
  accountId     String
  account       XhsAccount @relation(fields: [accountId], references: [id], onDelete: Cascade)
  draftId       String?
  title         String   @default("")
  content       String   @default("")
  scheduledDate String   // YYYY-MM-DD
  scheduledTime String   // HH:mm
  status        String   @default("pending") // pending, published, skipped
  notes         String   @default("")
  createdAt     DateTime @default(now())

  @@index([accountId])
  @@index([scheduledDate])
}
```
