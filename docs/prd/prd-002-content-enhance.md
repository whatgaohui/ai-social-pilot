# PRD-002: 内容库增强 — 详情查看 + 标签搜索

> **优先级**: P0  
> **日期**: 2026-05-07  
> **状态**: 待确认  

---

## 一、问题描述

1. 内容库中点击素材无法查看详情（图片/视频只能看到缩略图）
2. 素材可以添加标签但无法按标签搜索或过滤，标签功能形同虚设

## 二、目标

| 指标 | 当前 | 目标 |
|------|------|------|
| 素材详情查看 | 不支持 | 支持图片原图 + 视频播放 |
| 标签搜索 | 不支持 | 支持单/多标签筛选 |
| 图片原图查看 | 仅缩略图 | 新窗口打开高清原图 |
| 视频播放 | 不支持 | 内嵌播放器 |

## 三、功能设计

### 3.1 素材详情弹窗

**交互流程**：
```
内容库列表 → 点击素材卡片 → 打开详情弹窗（Dialog）
```

**弹窗内容**：
- 顶部：媒体展示区
  - 图片笔记：ImageCarousel 轮播（复用笔记详情已有组件）
  - 视频笔记：HTML5 `<video>` 播放器
  - 支持点击原图/原视频（右键保存或新标签打开）
- 中部：标题 + 正文内容
- 底部：标签列表 + 数据统计（点赞/评论/收藏）

**弹窗尺寸**：max-w-4xl，max-h-[90vh]

### 3.2 标签搜索/过滤

**交互设计**：
```
内容库顶部工具栏增加：
┌──────────────────────────────────────────────┐
│ [搜索输入框] [标签下拉选择 ▾] [清除筛选]     │
└──────────────────────────────────────────────┘
```

1. **搜索输入框**：按标题/正文关键词搜索
2. **标签下拉选择**：
   - 多选（Checkbox 样式）
   - 显示所有已使用的标签 + 使用次数
   - 选择后实时过滤
   - 支持"与"(AND) 和"或"(OR) 模式，默认 OR
3. **清除筛选**：一键清除所有过滤条件

**API 设计**：
```
GET /api/content?search=关键词&tags=美食,探店&tagMode=or

响应：
{
  "posts": [...],
  "total": 15,
  "availableTags": [
    { "name": "美食", "count": 8 },
    { "name": "探店", "count": 5 }
  ]
}
```

### 3.3 标签聚合面板（可选增强）

在内容库右侧或底部增加标签云：
- 按使用频率排序
- 颜色深浅表示使用频率
- 点击标签自动过滤

| 风险 | 概率 | 影响 | 应对 |
