# PRD-004: 笔记日历弹层尺寸调整

> **优先级**: P1  
> **日期**: 2026-05-07  
> **状态**: 待确认  

---

## 一、问题描述

笔记日历中的笔记详情弹层和新建笔记弹层尺寸过小，内容显示不完整，操作空间不足。

## 二、目标

| 组件 | 当前尺寸 | 目标尺寸 |
|------|----------|----------|
| 笔记详情弹层 | 不完整 | max-w-5xl, max-h-[95vh] |
| 新建笔记弹层 | 不完整 | max-w-3xl, max-h-[90vh] |
| 内容溢出 | 截断 | 内部滚动 + 自适应高度 |

## 三、功能设计

### 3.1 笔记详情弹层

- 尺寸从当前尺寸调整为 `max-w-5xl`（约1280px）
- 高度 `max-h-[95vh]`，内部可滚动
- 布局：左右分栏
  ```
  ┌─────────────────────────────────────────────┐
  │ 笔记详情                          [×] 关闭   │
  │─────────────────────────────────────────────│
  │ [左侧 60%]        │ [右侧 40%]               │
  │ 媒体展示区         │ 标题 + 正文              │
  │ (轮播/视频)        │ 数据统计                  │
  │                   │ 标签                      │
  │                   │ AI分析                    │
  │                   │ 采集状态                  │
  └─────────────────────────────────────────────┘
  ```

### 3.2 新建笔记弹层

- 尺寸调整为 `max-w-3xl`（约768px）
- 高度 `max-h-[90vh]`，内部可滚动
- 表单字段清晰分区：
  ```
  ┌───────────────────────────────────┐
  │ 新建笔记                [×] 关闭   │
  │───────────────────────────────────│
  │ 标题: [________________]          │
  │ 类型: (●) 图文  (○) 视频          │
  │ ───────────────────────────────   │
  │ 媒体上传:                          │
  │ [拖拽上传区域]                     │
  │ [支持 jpg/png/mp4, 最多9张图/1视频] │
  │ ───────────────────────────────   │
  │ 正文:                              │
  │ [多行文本框, 支持1000字]            │
  │ ───────────────────────────────   │
  │ 标签: [#美食探店] [#成都] [+添加]   │
  │ ───────────────────────────────   │
  │ 发布方式: (●) 立即发布 (○) 定时    │
  │ 定时时间: [2026-05-08 18:00]      │
  │ ───────────────────────────────   │
  │ [AI辅助创作]   [保存草稿]   [发布] │
  └───────────────────────────────────┘
  ```

- [ ] 响应式：在1280px以下屏幕自动适配
