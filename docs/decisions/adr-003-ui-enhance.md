# ADR-003: 笔记详情前端展示增强

## 状态: 已采纳
## 日期: 2026-05-07
## 背景: 笔记详情采集已支持图片组和视频 URL，但前端只显示封面图。需要增强笔记详情抽屉的媒体展示能力。

## 决策: 
- 新增 `ImageCarousel` 组件: 图片组轮播，左右箭头导航，底部圆点指示器，右上角显示当前/总数
- 视频笔记使用 HTML5 `<video>` 元素 (controls, preload=metadata)，fallback 到封面图
- 笔记卡片左上角显示采集状态 badge: 已采集(绿)/待采集(橙)
- 笔记详情抽屉底部显示详细采集状态提示框

## 后果:
- **好处**: 用户可以直观看到笔记的完整图片组和视频，不再只显示单张封面图
- **代价**: NoteCard 和 NoteDetailDrawer 组件增加约 100 行代码
