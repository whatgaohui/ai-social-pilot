# 笔记详情前端展示增强

## 日期: 2026-05-07

## 问题描述

笔记详情抽屉只显示封面图，看不到完整的图片组和视频。

## 解决方案

- 新增 `ImageCarousel` 组件：图片组轮播，支持左右箭头和底部圆点导航
- 视频笔记使用 HTML5 `<video>` 播放器
- 笔记卡片左上角显示采集状态 badge（绿色已采集/橙色待采集）
- 笔记详情抽屉底部显示采集状态提示框

## 技术决策

1. **图片轮播选择**：不使用第三方库（如 Swiper），自己实现简单的 ImageCarousel 组件。
   - 理由：只需要最基本的左右切换 + 指示器功能，引入第三方库会增加 bundle 大小
   - 实现约 50 行代码，功能完整

2. **视频播放器选择**：HTML5 `<video>` 原生元素。
   - 理由：小红书的视频 URL 通常有防盗链和时效性，不需要复杂的播放器功能
   - 设置 `controls` 和 `preload="metadata"`，浏览器自动处理解码

3. **采集状态指示**：双色 badge 方案。
   - 绿色 + CheckCircle2 = 已采集（相对时间）
   - 橙色 + AlertCircle = 待采集
   - 避免使用红色（红色在 XHS 品牌色中是主色，会混淆）
