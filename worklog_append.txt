### 导出接口

1. **useDragSort<T> Hook**
   - 通用泛型拖拽排序 hook，支持任意类型数组
   - 参数：`items: T[]` + `onReorder: (newItems: T[]) => void`
   - 返回值：
     - `dragHandlers`: { onDragStart, onDragOver, onDragLeave, onDrop, onDragEnd }
     - `dragState`: { draggedIndex, overIndex, isDragging, dropPosition }
     - `reorder(fromIndex, toIndex)`: 编程式重排辅助方法
     - `items`: 当前 items 引用
   - 实现：
     - 使用 HTML5 原生 Drag and Drop API
     - useRef + useEffect 保持 items 快照最新（避免渲染期 ref 更新）
     - 拖拽位置检测：根据鼠标在目标元素的上半/下半部分判断 "before"/"after"
     - 智能插入：先移除再插入，正确处理跨位拖拽的索引偏移

2. **SortableItem 组件**
   - 包装任意列表项为可拖拽元素
   - Props：`index, children, dragHandlers, dragState, className?, onClick?, isSelected?`
   - 功能：
     - GripVertical 拖拽手柄（hover 时显示，拖拽时常驻）
     - 拖拽项：opacity-50 + scale-95 + z-50
     - 放置指示线：violet→purple→fuchsia 渐变色，3px 高度
     - 根据 dropPosition 在上方或下方显示指示线
     - 悬停目标：violet 边框 + violet-50/10 背景
     - 选中状态：ring-2 ring-primary 高亮
     - framer-motion layout 动画（spring 刚度350，阻尼28）
     - 点击抑制：拖拽结束后不触发 onClick
     - AnimatePresence 入场动画（opacity + y 偏移）

3. **类型导出**
   - DropPosition: "before" | "after" | null
   - DragState: { draggedIndex, overIndex, isDragging, dropPosition }
   - DragHandlers: { onDragStart, onDragOver, onDragLeave, onDrop, onDragEnd }
   - UseDragSortReturn<T>: hook 完整返回类型
   - SortableItemProps: 组件 Props 类型

### 设计特性
- **原生 HTML5 DnD**：无外部库依赖，跨浏览器兼容
- **精确放置指示**：上半/下半检测确保插入位置准确
- **framer-motion 动画**：spring 物理弹性 + layout 自动布局动画
- **平台筛选兼容**：hook 接受已过滤的 items，自然兼容 platformFilter
- **独立封装**：不修改 content-calendar.tsx，集成时只需包裹列表项

### 集成示例
```tsx
const { dragHandlers, dragState, reorder } = useDragSort(filteredPosts, setPosts);
{filteredPosts.map((post, i) => (
  <SortableItem key={post.id} index={i} dragHandlers={dragHandlers} dragState={dragState}>
    <PostCard post={post} />
  </SortableItem>
))}
```
